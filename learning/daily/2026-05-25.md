# 2026-05-25 学习记录

## 今日主题

初始化智能体学习体系；区分普通 LLM 调用、工作流和智能体；理解智能体最小闭环；区分状态和记忆。

## 苏格拉底问题

1. 你认为“智能体”和“普通调用一次大模型接口”的根本区别是什么？
2. 如果一个智能体会调用工具，谁来决定什么时候调用、调用哪个工具、如何处理失败？
3. 你希望第一个实战智能体解决什么具体问题？

## 我的回答

1. “问 ChatGPT 一个问题，它回答你”不算智能体。
2. 固定执行 `读取文件 -> 总结 -> 生成报告` 更像工作流。
3. 智能体比普通 LLM 调用多出的关键能力是“能真正执行”。
4. 最小智能体应该有一个流程，每个流程节点通过 LLM 根据上一个节点得到的结论判断接下来的走向，最终输出一个稳定结论。
5. 查资料智能体可以概括为：搜索、查询、判断、验证。
6. 状态是当前一个时刻的即时反馈，记忆是长期的。

## 纠正与补充

- 前两个判断正确：一次问答通常只是普通 LLM 调用；固定步骤执行更接近工作流。
- 第三个回答方向正确，但需要更精确：智能体不只是“能执行”，而是能围绕目标，根据上下文和状态决定下一步，必要时调用工具，观察结果，再决定继续、重试或结束。
- 简单边界：
  - 普通 LLM 调用：输入一次，输出一次。
  - 工作流：步骤预先固定，模型可能只是某些步骤里的处理器。
  - 智能体：目标明确，但路径可能动态变化，会决策、行动、观察并迭代。
- 最小智能体闭环可以表达为：目标输入 -> 状态/上下文 -> 决策 -> 行动/工具调用 -> 观察结果 -> 判断继续或结束 -> 输出。
- “稳定结论”不是只靠生成一次答案，而是要有停止条件：信息足够、任务完成、工具失败不可恢复、达到预算上限等。
- “搜索、查询、判断、验证”已经覆盖了行动、观察和部分决策；完整表达还需要补上目标、状态和停止条件。
- 状态和记忆的方向判断正确。更工程化地说：状态是一次任务运行中的当前进展、变量、中间结果和下一步依据；记忆是跨任务保留、未来还能复用的信息，例如用户偏好、长期事实、历史经验。
- 状态通常随着一次任务结束而清空或归档；记忆需要经过筛选，不能把所有状态都长期保存。

## 今日练习

用自己的话回答：

> 用“目标、状态、决策、行动、观察、停止条件”六个词，描述一个查资料智能体如何完成任务。

练习答案：

- 目标：查清某个问题。
- 状态：记录已搜索关键词、已读资料、可信来源和未解决问题。
- 决策：判断下一步是继续搜索、换关键词、阅读来源、交叉验证还是输出。
- 行动：搜索、查询、读取资料。
- 观察：判断资料是否相关、可靠、互相矛盾。
- 停止条件：来源足够可靠、结论一致，或信息不足需要说明限制。
