# 学习记录规则

## 目录职责

- `learning/daily/`：每天的学习成果、关键问题、练习和复盘。
- `learning/progress.md`：总体学习进度和里程碑。
- `learning/mistakes.md`：错题本，记录误解、纠正和复测状态。
- `learning/todo.md`：待办事项，记录下一步学习和项目任务。
- `docs/agent-architecture.md`：智能体总体架构沉淀。

## 每日记录格式

每日文件命名：`YYYY-MM-DD.md`。

建议包含：

- 今日主题
- 苏格拉底问题
- 我的回答
- 纠正与补充
- 今日成果
- 今日练习
- 待复习点

## 进度规则

更新 `learning/progress.md` 时，保持三个层级：

- 当前阶段
- 已掌握
- 下一步

## 错题本规则

错题必须包含：

- 错误理解
- 正确理解
- 触发场景
- 复测问题
- 状态：待复测 / 已掌握

## Todo 规则

todo 使用复选框：

- `[ ]` 未完成
- `[x]` 已完成

每个 todo 尽量写成可验证动作。

## Git 提交规则

每当一个知识点学习完成后：

- 优先更新 `learning/` 下的学习成果、进度、错题本和 todo。
- 自行创建 Git 提交，提交信息应简短说明本次完成的知识点。
- 提交后推送到 GitHub 远端 `origin/main`。
- 如果推送失败，明确说明失败原因和当前本地提交状态。
