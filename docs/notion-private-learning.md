## 已学知识点摘要

### 普通 LLM 调用、工作流、智能体

- 普通 LLM 调用：输入一次，输出一次。
- 工作流：步骤固定，模型可能只是某个节点里的处理器。
- 智能体：目标明确，但路径可以动态变化，会决策、行动、观察并迭代。

### 会调用工具不一定等于智能体

如果一个系统每次都固定执行“搜索一次 -> 总结答案”，它仍然更像带工具的工作流。关键区别在于它是否会根据观察结果动态决定下一步。

### 智能体最小闭环

六要素：

- 目标：用户要完成什么。
- 状态：当前已知信息、已执行步骤、中间结果和限制。
- 决策：下一步做什么，是否需要调用工具。
- 行动：执行模型输出、工具调用、文件操作或其他外部动作。
- 观察：读取行动结果，判断是否有效、是否失败、是否需要补充信息。
- 停止条件：任务完成、信息足够、失败不可恢复、达到预算或需要人类确认。

### 查资料智能体练习

学习者概括为：搜索、查询、判断、验证。

补完整表达：

- 目标：查清某个问题。
- 状态：记录已搜索关键词、已读资料、可信来源和未解决问题。
- 决策：判断下一步是继续搜索、换关键词、阅读来源、交叉验证还是输出。
- 行动：搜索、查询、读取资料。
- 观察：判断资料是否相关、可靠、互相矛盾。
- 停止条件：来源足够可靠、结论一致，或信息不足需要说明限制。

### 状态和记忆

- 状态：一次任务运行中的当前进展、变量、中间结果和下一步依据。
- 记忆：跨任务保留、未来还能复用的信息，例如用户偏好、长期事实、历史经验。
- 不是所有状态都应该进入记忆，只有未来可复用、稳定、经过确认的信息才适合长期保存。
